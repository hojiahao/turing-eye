# Rust / Node 浏览器工具协议

2026-09-18，协议 `2.0`，技术评审基线。依据[技术方案](../docs/Agent评审平台技术方案.md#浏览器与源码工具)，供 R1 消费契约测试使用。字段权威为同目录 [tool-protocol.schema.json](tool-protocol.schema.json)，JSON Schema Draft 2020-12，全部引用在文件内。本文补充跨消息、资源与安全约束；设计检查通过不表示 Rust/Node 实现或浏览器联调已验收。

## 1. 边界与版本

Rust Worker 管理有限 Node 进程，每个 Node 复用受控 Chromium 池，每个 Run 的当前取证尝试独占一个非持久化 BrowserContext 和主 Page。不同 Run 不共享 Cookie、Storage、页面或输入状态。更换 attempt 创建新 session，不能接管旧 Context。源码 `read/search` 是 Runtime 的只读工具，由源码适配器执行，不进入本协议。

Rust 负责身份、冻结策略、预算、租约和最终提交权。Node 只执行列出的浏览器操作，不持有数据库、LLM 或 S3 凭据，不写分数，不提供 shell、任意 JavaScript/evaluate、文件路径、代码写入、包安装或插件注册接口。这里不新增业务 HTTP API。

进程启动时由 Worker 选择匹配 `2.0` 的工具构建，记录 Node/Playwright/Chromium 构建及策略修订。每帧仍校验 `protocol_version`，不自动降级或忽略未知字段。改变字段、枚举或语义需要新协议版本和配套消费测试，不能因目录也叫 v2 就与业务 API 版本联动。无握手、心跳或第二套事件流。公开 `RuntimeEvent` 统一使用同目录 `openapi.json` 的 `components.schemas`，本 Schema 不依赖它，`facts` 不替代它。

## 2. 传输与限额

标准输入只接收 `request`，标准输出只发送 `result | error`。UTF-8，无 BOM，每行一个 JSON 对象，以单个 LF 结束，字符串内换行必须转义。禁止空行、JSON 数组、重复键、NaN/Infinity、截断帧及启动提示。并发写入必须整帧串行化，跨 session 的响应可以乱序，同一请求只产生一个终态响应。进程退出或管道断开可能没有响应，不能据此推断操作未发生。

stdout 严禁日志，包括依赖和浏览器调试输出。stderr 仅允许有界、脱敏诊断，记录稳定原因、关联 ID 和阶段，不能输出原始请求/返回体、环境变量、Cookie、Authorization、签名 URL、输入文本、隐藏推理或系统提示。Worker 同样限制 stderr 缓冲并持续排空，不能让日志洪泛阻塞取消。

| 项目 | 2.0 约束与单位 |
| --- | --- |
| 单请求 | 最多 65,536 UTF-8 字节，计入 LF，读取时限流，不先无限缓存再检查 |
| 单响应 | 不超过请求 `max_result_bytes`，8,192..262,144 字节，计入全部 envelope、facts、产物元数据与 LF |
| 字符串/数组 | Schema 中长度是 Unicode 字符数，不能代替 UTF-8 字节预算；所有对象禁止额外属性，数组有上限 |
| 普通调用 deadline | UTC 毫秒时间 `YYYY-MM-DDTHH:mm:ss.sssZ`，排队也耗预算；接收时剩余不超过 120,000 ms，且不晚于任务与 session deadline |
| Session 到期 | 创建时 `expires_at` 不晚于 TaskSpec 总 deadline，距创建最多 1,800,000 ms，不能续期；到期自主停止接纳并清理 |
| 清理宽限 | cancel/close 可在业务 deadline 后使用独立的最多 5,000 ms 清理预算，只释放资源，不恢复取证或提交权 |
| 计时与坐标 | `duration_ms` 为 Node 接收至终态的单调时钟耗时，含排队；坐标、滚轮和 viewport 使用 CSS px，截图 device scale 固定为 1 |
| 暂存产物 | 每项 1..8,388,608 字节，一帧最多 4 项，session 未消费文件合计最多 67,108,864 字节；禁止 base64 大图塞入 JSONL |

Node 和 Rust 都执行帧上限及 deadline 检查。Rust 按本地单调计时保留发出时预算，不能因时钟回拨或重试延长 TaskSpec。总预算跨 attempts 累计，模型等待期间 Context 继续占用槽位。进程数、每进程 Context 数、在途请求、历史关联表及日志/网络缓冲均必须有正数硬上限；配置缺失不得无限放行。这些是协议防护上限，不是已验证容量或性能推荐值。

Rust 每个 session 至多发出一个普通调用，收到终态后再发下一次。Node 拒绝超额普通调用，不能建立无界队列。cancel/close 使用单独控制通道逻辑和预留预算，经同一 stdin 传输，但不能排在挂起操作后等待。关闭 stdin、父进程退出和 session 到期都触发清理，不能只依赖一次 cancel 成功送达。

有合法版本、工具、归属和预算的请求若参数错误，可返回 `INVALID_ARGUMENT`。未知版本/工具、无法可信关联的坏帧、重复请求 ID、非法 UTF-8 或超长帧均视为管道协议故障：不执行、不虚构关联响应，stderr 输出脱敏原因并关闭该进程通道，由 Worker 回收进程树。Worker 收到非法或超长响应也隔离该进程，并将未确认调用记为结果未知。没有响应时由 Rust 记录本地传输故障，不伪造 Node 回执。

## 3. 归属与工具联合类型

请求必须包含 Schema 声明的全部公共字段；没有隐式默认值。所有结果和错误原样回显 `request_id/call_id/owner/session_id/tool`。浏览器任务必须绑定 Run，`owner` 及其字段不可空，不能借用尚无 Run 的 Planner/预览任务调用浏览器。

| 字段 | 生成方与语义 |
| --- | --- |
| request_id | Rust 生成的一次 JSONL 往返身份，跨进程重建也不复用，不是平台 HTTP 请求 ID |
| call_id | Runtime 宿主生成的一次实际工具调用身份，不能直接信任模型给出的 ID；本协议一次 call 对应一次 request，重试新建二者并保留上次结果 |
| owner | `tenant_id/run_id/task_id/attempt_id/attempt_generation` 全部由 Rust 填入；代次是持久化任务的递增 fencing 值，1..2,147,483,647，与模型轮次不同 |
| session_id | Rust 在首次 open 前分配，绑定进程实例及完整 owner，因此 Context 尚未创建也能取消；新进程、Run 或 attempt 不复用 |
| target_request_id / target_call_id | cancel 同时指向该 session 内同 owner 的一个已接纳普通调用，不能指向自己、另一 cancel/close 或他人 session |

Node 按已绑定身份校验后续操作，不能用调用方提交的新 owner 覆盖会话归属。Rust 收包时与在途表逐字段核对；Schema 无法证明这些跨帧相等关系。ID 不是授权凭据。重复帧不重执行，协议不承担点击、导航等副作用的透明重试或“恰好一次”保证。

| tool | 请求 params | 成功 data 与限定 |
| --- | --- | --- |
| open | `mode=create` 必需 url、policy、viewport、expires_at；`mode=navigate` 仅 url | create 原子占用 session 槽位并建 Context，navigate 仅操作现有主 Page；返回 `context_state=open` 和脱敏 page，表示到达 DOMContentLoaded，不表示作品健康、全部资源加载或业务成功 |
| observe | 显式 include_dom/include_screenshot，至少一个 true | page、dom、screenshot_handle 均必填；未请求项为 null，请求项必须存在。DOM 为有界、脱敏的可见结构文本及 truncated 标记，截图仅当前 viewport；Canvas 不因 DOM 空而判失败 |
| mouse | click、move、down、up、wheel 的封闭参数联合 | `dispatched=true` 仅表示输入调用已完成，不表示应用已响应或目标完成；坐标还必须落在实际 viewport 内 |
| keyboard | press/down/up + 固定 key，或 type + 1..4096 字符文本 | 同上；Space 等协议键由适配器映射，组合键使用 down/press/up；不接受脚本或任意浏览器快捷命令字符串 |
| console | after_sequence、limit | 只读脱敏日志，返回 entries、next_after_sequence、has_more、gap，不执行控制台表达式 |
| network | 同 console | 只读已有 HTTP/WS 连接元数据与错误，不主动重发请求、不读取请求/响应正文、header、Cookie 或 WS 帧内容 |
| cancel | target 两个 ID + 固定 reason | 回显 target，disposition 为 accepted 或 already_terminal，context_state 为 closing 或 closed；这是取消与清理受理回执 |
| close | 空对象 | 只有实际确认所属 Context 关闭后才返回 `context_state=closed`；空闲会话直接 close，不需要伪造 cancel target |

create 验证通过后先登记 session 再启动异步创建/导航，取消可封住仍在创建的 Context，晚创建成功的 Context 必须立即关闭，不能重新标 open。重复 create 返回 `SESSION_CONFLICT`，不新建第二个 Context。create 失败也保留归属和关闭记录；只有确认从未分配资源时错误可报 absent。navigate 不会隐式创建 session，也不能修改策略/viewport/期限。

单 session 使用一个主 Page；意外弹窗拒绝并关闭，不隐式切换页面，下载/文件选择/权限授权默认拒绝。浏览器内部固定采集脚本不是向模型开放 evaluate。新的多页、文件上传或授权能力须另行评审。

console/network 各有独立 session 内严格递增安全整数序号，与公开 Run 事件 sequence 不同。读取从 after_sequence 之后开始，返回条数不超过 limit，且受响应字节上限限制。next_after_sequence 为最后已交付序号，空结果保留请求位置；has_more 表示当前还有未交付缓存，gap 表示请求之后已有记录因有界缓冲被淘汰。游标超出该流已产生水位返回 INVALID_ARGUMENT，不能静默跳过未来记录。两次读取可以重复返回同一记录，读取不清空缓冲；重建 session 重置流。缺日志不代表没有错误。Network 的 status_code/failure 至少一个非 null，未知耗时用 null，不能伪造 0；404 本身是观测数据，不是工具协议失败。

## 4. 授权、取消与迟到结果

create 的 policy 是 Rust 从冻结 TaskSpec 构造的受信快照，不由模型填写。revision 标识同一不可变策略，navigation_origins 只限制顶层导航；点击、脚本导航和重定向同样检查。origin 按规范化 scheme/host/port 精确匹配，不允许通配；必须已获该作品对应 origin 的完整授权，不能把仅子路径授权扩大成整个共享域名。无法用本版本表达的授权范围拒绝创建，不能先放行再补策略。

子资源可访问授权 origin 和精确私网绑定，allow_public_subresources=true 另允许经出网检查的公网 CDN、iframe、HTTP(S)/WS(S) 连接，false 不禁止已明确授权的目标。判断同源 WS 时将 ws/wss 分别对应 http/https，host/有效端口仍需匹配。不能将所有资源强制同源，也不能借子资源放行私网。默认不开放浏览器宿主资源、loopback、link-local、云元数据或 file/javascript 等 URL 能力。

private_target_ids 只能引用 Worker 在 Node 启动时以只读配置提供的精确可信绑定，包含租户、作品、scheme/host/port 和实际 IP 范围。未知或归属不符的绑定拒绝，不能以任意私网 URL 替代 ID。新增绑定先配置新工具进程，不热改旧 session 的策略。URL 规范化、DNS 解析、每次重定向、WS 握手以及实际连接目标都需检查；仅 Playwright 路由拦截或域名正则不足以证明出网隔离，部署还须受控出口。秘密不进入 URL/键入参数，授权 ID 也不等同秘密凭据。

会话状态顺序为 creating → open → closing → closed。closed 不重新打开，只保留有界归属记录供幂等 close 和取消竞争判断；关联表达到上限时停止接纳并在存量结束后轮换进程，不直接丢弃仍可能被引用的记录。

1. Worker 先按 jobs 契约持久化取消或确认失租，立即停止新取证和有效结果提交，再发 cancel。Node 核对 target、原 owner 和 session，在控制路径封住整个 session 并开始关闭 Context，取消会影响该 session 的全部未完成普通调用。
2. cancel 返回 accepted 不代表目标已停，already_terminal 只表示目标调用已有终态。这两种情况仍关闭所属 session；返回 closing 时 Rust 随后发 close 等待实际释放。原调用仍需自己的终态响应，取消前已终态的调用不能再发第二个响应。
3. Node 可先对原调用返回 CANCELLED/DEADLINE_EXCEEDED，`local_execution=unknown`、`context_state=closing`，不能谎称 stopped。若停止已确认，才写 stopped；导航/点击可能已触发远端操作，external_effects 仍为 possible。close 成功也仅确认本地 Context 已释放，不证明远端请求、任务或副作用被撤销。
4. 清理宽限内无确认时，Worker 终止并回收该 Node 及其 Chromium 子进程，核实退出后再归还槽位。共享进程内其他 Context 受影响应记录服务故障，不能归因于选手。未核实退出则保留未知和资源占用，不能凭 Promise/Future 被丢弃、超时胜出或断管判定释放。
5. 对迟到、重复或来源不匹配的响应仅保留隔离的脱敏诊断和待清理产物，不送入当前 Judge。接纳调用结果时检查本次调用及任务 deadline；证据登记、评分提交还须检查各自当前任务的租户、Run、冻结规则、attempt/代次、有效租约及取消状态。数据库条件提交是最后门禁，不能只信 Node 的 completed_at。已及时接纳并登记的证据不会仅因其历史调用 deadline 过去而失效。清理允许引用旧 owner，但不恢复旧 attempt 的提交权。

点击后断管等结果未知情形，不能盲目重放输入。先按预算重新观察或在新隔离会话恢复取证，保留已经存好的证据；重建不声称恢复原页面状态。取消与完成竞争以数据库实际提交为准，已经有效保存的分数不因取消、文案或报告失败被删除。

## 5. facts、产物与错误

每个响应 envelope 本身是可审计记录。facts 是可选内容的必填数组，可为空，记录工具直接观察的短事实，含 session 内唯一 fact_id、采集时间、固定种类、模板摘要、指向本帧 data/error 的 JSON Pointer 及暂存句柄。指针必须存在，句柄必须出现在本帧 artifacts，不能引用别的 session。它们不是模型结论，不含评分、思维链或系统提示；网页内容始终按不可信数据处理。Worker 关联冻结策略/构建及完整归属后保存，公开事件只投影脱敏动作、用量和已 ready 的证据引用。

artifacts 中的 handle 不是正式 artifact_id、S3 key 或可下载 URL。工具启动配置给出私有 spool 根目录，Worker 为 session 建目录，Node 只能在 `<spool_root>/<session_id>/<handle>` 写新文件，句柄不含路径分隔符且不复用。响应前文件须完整关闭并不可变；Rust 按归属打开普通文件，拒绝符号链接/路径逃逸，校验大小、格式、摘要后上传，再事务登记 ready，最后才能形成正式 evidence_refs。Node 给出的 sha256 不是免检凭据。

关闭 Context 不删除仍待消费的 spool 文件。Rust 登记成功后按句柄回收，失败/失租产物按有界清理记录处理，不能在 GET 中修复或关闭完整性校验。DOM、操作事实和只读流可由 Rust 从已验证响应生成规范产物；Node 无需为每个小对象另写文件。请求两类观察但仅一类采集成功时，返回错误并保留实际已完成的暂存产物，不以部分结果冒充全部成功。DOM 截断和日志缺口必须显式标记。

采集、序列化和公开投影均脱敏：移除 URL query/fragment/userinfo，遮蔽敏感路径、密码区域及已知秘密，DOM 不返回密码/隐藏输入值，截图不能跳过脱敏。无法安全保留的内容须省略并说明取证限制，不能假称完整证据。Schema 不能识别任意文本或图片里的秘密，R1/R5 必须验证实际处理。

错误与成功互斥：error 没有 data，result 没有 error。error.code、stage、retryable、detail、local_execution、context_state、external_effects 全部必填。local_execution 的 not_started 仅指本次调用未产生动作，此时 external_effects=none，不表示 Context 里旧页面的后台活动已停止。completed 可以与错误并存，例如动作完成但响应超限；stopped 需实际确认本次执行不再推进；无法确认则 unknown。retryable=true 仅表示恢复可能有意义，不授权重复有副作用的操作。

| 稳定错误码 | 归因及处理 |
| --- | --- |
| INVALID_ARGUMENT | 参数或跨字段约束不合法，修改输入，retryable=false |
| POLICY_DENIED | 未授权目标/动作，拒绝执行，retryable=false，不当作作品缺陷 |
| SESSION_UNAVAILABLE | 未知、别的进程或归属不符的会话，retryable=false，不披露其他租户状态 |
| SESSION_CONFLICT / SESSION_CLOSING | 重复 create / 会话已封住，retryable=false；closed 也拒绝普通操作 |
| CANCEL_TARGET_INVALID | target 不存在、两个 ID 不匹配或不属该 session，retryable=false，不取消其他调用 |
| CAPACITY_EXCEEDED | 进程/会话/缓存/暂存限额不足，未执行时可有界退避，不能无限入队 |
| DEADLINE_EXCEEDED / CANCELLED | 前者是预算耗尽，后者是取消意图；如实报告实际停止情况，CANCELLED 不自动重试 |
| BROWSER_DISCONNECTED | 工具/浏览器服务故障，影响范围按真实 Context 记录；先清理再考虑恢复 |
| NAVIGATION_FAILED / INPUT_FAILED / OBSERVATION_FAILED | 阶段分别为 navigate/input/observe，记录真实失败原因，不能仅凭错误码判定选手应扣分 |
| ARTIFACT_FAILED | 采集后的本地写入、完整性或脱敏处理失败，不伪造截图引用 |
| RESULT_TOO_LARGE | 合法响应不能装入总字节预算，stage=serialize，retryable=false；动作可能已完成，不可为了缩短输出重放动作 |
| INTERNAL_ERROR | 未分类的工具服务异常，内部诊断可关联，公开 detail 不附原始堆栈或秘密 |

必要事实/产物元数据超限不能无声删除来伪装完整成功。DOM/日志仅可按其显式截断/分页规则缩减，否则发有界错误，必要时 facts/artifacts 为空，剩余产物隔离清理。即便业务结果超限也预留 8 KiB 的错误帧空间。

## 6. 本地验证与 R1 消费

Schema 的 examples 是 18 帧脱敏黄金形状，覆盖全部八种工具、创建/导航、观察产物、取消受理、原调用未知终止与 close 确认。按数组顺序组成一条示意时序，日期固定用于校验，不能当作当前可执行 deadline；域名、大小和摘要均为占位，不对应真实访问或文件。工具请求/响应联合类型、参数、错误和产物的各层对象均关闭额外字段。console/network 的空 data 形状相同，内部使用 anyOf，外层仍由 tool 严格选择类型。

现有校验器为仓库 `ai-review-server/.venv/bin/python3` 内的 `jsonschema 4.26.0`，入口 `jsonschema.Draft202012Validator`；现有使用方式可见 `ai-review-server/app/eval_engine/infrastructure/environment_contract.py` 的 validator_for。前端 Ajv 6 不用于验证 Draft 2020-12。本环境没有 date-time/uri 可选检查器，下面使用标准库检查本协议的受限时间和 URL 格式，不声称实现通用 RFC 校验或出网授权。无新依赖，无外部请求，无浏览器进程。

从仓库根目录以该 Python 运行下方代码即可复核，代码只读取 Schema，在内存中构造样例，不写测试或实现文件：

```python
import copy
import json
from datetime import datetime
from pathlib import Path
from urllib.parse import urlsplit
from jsonschema import Draft202012Validator, FormatChecker

schema = json.loads(Path("contracts/tool-protocol.schema.json").read_text())
Draft202012Validator.check_schema(schema)
formats = FormatChecker()

@formats.checks("date-time", raises=ValueError)
def check_time(value):
    if not isinstance(value, str):
        return True
    datetime.strptime(value, "%Y-%m-%dT%H:%M:%S.%fZ")
    return True

@formats.checks("uri", raises=ValueError)
def check_uri(value):
    if not isinstance(value, str):
        return True
    url = urlsplit(value)
    return (url.scheme in ("http", "https", "ws", "wss") and bool(url.hostname)
            and url.username is None and url.password is None and "\\" not in value
            and (url.port is None or 1 <= url.port <= 65535))

validator = Draft202012Validator(schema, format_checker=formats)
examples = schema["examples"]
base = {(m["type"], m["request_id"]): m for m in examples}

def changed(kind, request, path, value):
    message = copy.deepcopy(base[kind, request])
    parent = message
    for key in path[:-1]:
        parent = parent[key]
    parent[path[-1]] = value
    return message

valid = list(examples)
for params in (
    {"action": "move", "x_px": 0, "y_px": 0},
    {"action": "down", "button": "left"},
    {"action": "up", "button": "left"},
    {"action": "wheel", "delta_x_px": 0, "delta_y_px": -4096},
):
    valid.append(changed("request", "req_mouse", ("params",), params))
for params in ({"action": "down", "key": "Shift"}, {"action": "up", "key": "Shift"},
               {"action": "type", "text": "Demo"}):
    valid.append(changed("request", "req_keyboard", ("params",), params))
for request in ("req_console", "req_network"):
    valid.append(changed("result", request, ("data",),
                         {"entries": [], "next_after_sequence": 0, "has_more": False, "gap": False}))
for field in ("dom", "screenshot_handle"):
    valid.append(changed("result", "req_observe", ("data", field), None))
network = copy.deepcopy(base["result", "req_network"])
network["data"]["entries"][0].update(status_code=None, failure="connection", duration_ms=None)
valid.append(network)
for code, local in (("DEADLINE_EXCEEDED", "unknown"), ("RESULT_TOO_LARGE", "completed")):
    error = copy.deepcopy(base["error", "req_navigate"])
    error["error"].update(code=code, local_execution=local,
                          stage="serialize" if code == "RESULT_TOO_LARGE" else "navigate")
    valid.append(error)
cancel = copy.deepcopy(base["result", "req_cancel"])
cancel["data"].update(disposition="already_terminal", context_state="closed")
valid.append(cancel)

mutations = [
    ("request", "req_open", ("protocol_version",), "1.0"),
    ("request", "req_open", ("tool",), "shell"),
    ("request", "req_open", ("command",), "pwd"),
    ("request", "req_open", ("session_id",), None),
    ("request", "req_open", ("request_id",), "x" * 65),
    ("request", "req_open", ("request_id",), "req_open\n"),
    ("request", "req_open", ("owner", "run_id"), None),
    ("request", "req_open", ("owner", "attempt_generation"), 0),
    ("request", "req_open", ("deadline_at",), "2026-02-30T08:00:00.000Z"),
    ("request", "req_open", ("deadline_at",), "2026-09-17T08:00:00"),
    ("request", "req_open", ("max_result_bytes",), 8191),
    ("request", "req_open", ("max_result_bytes",), 262145),
    ("request", "req_open", ("params", "url"), "file:///etc/passwd"),
    ("request", "req_open", ("params", "url"), "https://user:password@example.com/"),
    ("request", "req_open", ("params", "url"), "https://example.com:99999/"),
    ("request", "req_open", ("params", "url"), "https://example.com/\n"),
    ("request", "req_open", ("params", "policy", "navigation_origins"), ["https://*.example.com"]),
    ("request", "req_open", ("params", "policy", "navigation_origins"), ["https://example.com\n"]),
    ("request", "req_navigate", ("params", "viewport"), {"width_px": 1280, "height_px": 720}),
    ("request", "req_observe", ("params",), {"include_dom": False, "include_screenshot": False}),
    ("request", "req_mouse", ("params", "x_px"), -1),
    ("request", "req_mouse", ("params", "x_px"), 2560),
    ("request", "req_keyboard", ("params", "key"), "Control+c"),
    ("request", "req_keyboard", ("params", "key"), "a\n"),
    ("request", "req_keyboard", ("params",), {"action": "type", "text": "x" * 4097}),
    ("request", "req_console", ("params", "limit"), 101),
    ("request", "req_cancel", ("params", "target_call_id"), None),
    ("result", "req_open", ("data",), {"dispatched": True}),
    ("result", "req_open", ("data", "page", "url"), "https://game.example.com/?token=redacted"),
    ("result", "req_open", ("data", "page", "url"), "https://game.example.com/\n"),
    ("result", "req_open", ("data", "page", "url"), "wss://game.example.com/"),
    ("result", "req_observe", ("data", "dom", "text"), "x" * 16385),
    ("result", "req_observe", ("artifacts", 0, "handle"), "../capture"),
    ("result", "req_observe", ("artifacts", 0, "byte_length"), 8388609),
    ("result", "req_observe", ("artifacts", 0, "sha256"), "bad"),
    ("result", "req_observe", ("facts", 0, "reasoning"), "not allowed"),
    ("result", "req_observe", ("facts", 0, "value_path"), "/data\n"),
    ("result", "req_network", ("data", "entries", 0, "status_code"), 0),
    ("result", "req_network", ("data", "entries", 0, "status_code"), None),
    ("result", "req_network", ("data", "entries", 0, "method"), "GET\n"),
    ("result", "req_close", ("data", "context_state"), "closing"),
    ("error", "req_navigate", ("data",), {}),
    ("error", "req_navigate", ("error", "code"), "UNKNOWN"),
    ("error", "req_navigate", ("error", "retryable"), True),
    ("error", "req_navigate", ("error", "local_execution"), "not_started"),
]
invalid = [changed(*mutation) for mutation in mutations]
for message in examples:
    for key in message:
        missing = copy.deepcopy(message)
        del missing[key]
        invalid.append(missing)
for index, message in enumerate(valid):
    validator.validate(message)
for index, message in enumerate(invalid):
    assert not validator.is_valid(message), ("unexpectedly valid", index)

def inspect(node):
    if isinstance(node, dict):
        if node.get("type") == "object":
            assert node.get("additionalProperties") is False
        if "$ref" in node:
            assert node["$ref"].startswith("#/$defs/")
        for value in node.values():
            inspect(value)
    elif isinstance(node, list):
        for value in node:
            inspect(value)
inspect(schema)

requests = {m["request_id"]: m for m in examples if m["type"] == "request"}
def matches_call(response, request):
    return all(response[key] == request[key]
               for key in ("request_id", "call_id", "owner", "session_id", "tool"))

replies = set()
for message in examples:
    limit = 65536 if message["type"] == "request" else requests[message["request_id"]]["max_result_bytes"]
    assert len(json.dumps(message, ensure_ascii=False, separators=(",", ":")).encode()) + 1 <= limit
    if message["type"] == "request":
        continue
    assert message["request_id"] not in replies
    replies.add(message["request_id"])
    request = requests[message["request_id"]]
    assert matches_call(message, request)
    handles = {a["handle"] for a in message["artifacts"]}
    assert len(handles) == len(message["artifacts"])
    if message["type"] == "result" and message["tool"] == "observe":
        assert message["data"]["screenshot_handle"] in handles
    for fact in message["facts"]:
        value = message
        for token in fact["value_path"].split("/")[1:]:
            token = token.replace("~1", "/").replace("~0", "~")
            value = value[int(token)] if isinstance(value, list) else value[token]
        assert set(fact["artifact_handles"]) <= handles
cancel_request = requests["req_cancel"]
target = requests[cancel_request["params"]["target_request_id"]]
assert target["call_id"] == cancel_request["params"]["target_call_id"]
assert target["owner"] == cancel_request["owner"] and target["session_id"] == cancel_request["session_id"]
assert replies == requests.keys()
for path, value in ((("call_id",), "call_other"), (("session_id",), "session_other"),
                    (("owner", "tenant_id"), "tenant_other"), (("owner", "run_id"), "run_other"),
                    (("owner", "attempt_id"), "attempt_old"), (("owner", "attempt_generation"), 2)):
    mismatch = changed("result", "req_open", path, value)
    validator.validate(mismatch)
    assert not matches_call(mismatch, requests["req_open"])
print(f"PASS: schema; {len(valid)} valid; {len(invalid)} invalid; 6 mismatched links; example links/bytes; closed objects/local refs")
```
